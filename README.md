# Library Management System (Java)

A desktop application to keep track of books in a library.

## Features

- Login screen
- Librarian window to add and manage books
- Student window to browse and borrow books

## Built with

Java and Swing (NetBeans GUI designer).

## How to run

Open the project in NetBeans (or another Java IDE) and run the main class. The `.form` files are NetBeans GUI designer files for the Swing windows.
